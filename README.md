# RetroFlash.js
A lightweight, dependency-free Flash SWF player and ActionScript runtime, built entirely in JavaScript and HTML5 Canvas. The goal is to bring classic Flash animations and games back to modern browsers without plugins or WebAssembly.

## Current state

The player does not exist yet. What exists today is the SWF structure reader in [`src/`](./src/) (v0.2). It reads FWS and CWS headers and builds a bounds-checked tag index, including the contents of `DefineSprite`. It also decodes placement records (`MATRIX`, `CXFORM`, `CXFORMWITHALPHA`) and reports malformed or unsupported content explicitly.

It does not render anything and never executes ActionScript. The browser demo is [`demo/index.html`](./demo/index.html); open it directly, no server needed.

## Tests

```sh
node tests/run.js
```

Requires Node 16 or later and installs nothing. The fixtures are generated by the project itself, in [`tests/fixtures/`](./tests/fixtures/). What is verified, and how, is listed in [`tests/COMPATIBILITY.md`](./tests/COMPATIBILITY.md).
