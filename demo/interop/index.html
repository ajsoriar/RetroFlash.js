Legacy page scripting

An unchanged Flash-era page: an <object> with a nested <embed>, FlashVars, a legacyMovie_DoFSCommand handler, page functions for ExternalInterface.call, and buttons that script the movie with the plugin's methods (SetVariable, GotoFrame, TGotoLabel, …) and its ExternalInterface.addCallback functions. The only change is the script tags at the end of the page, which load RetroFlash.js. The movie is interop.swf, built by node tests/fixtures/interop.js (ActionScript 2). Serve this folder over HTTP: npx http-server . from the project root, then open /demo/interop/.
