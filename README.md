# RetroFlash.js
A lightweight, dependency-free Flash SWF player and ActionScript runtime built entirely in JavaScript and HTML5 Canvas. Bringing classic Flash animations and games back to modern browsers without plugins or WebAssembly.

## Included prototype

[`swf-reader-phase1/`](./swf-reader-phase1/) contains an isolated phase-one SWF structure reader. The browser demo is available at [`demos/test-001/`](./demos/test-001/). The reader is not yet integrated with the player/runtime, does not render animations, and never executes ActionScript.
