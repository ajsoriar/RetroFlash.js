# Compatibility report — SWFReader 0.2.0

This file lists only what the tests demonstrate. Anything that is not listed here is unverified.

## How to verify

```sh
node tests/run.js                        # all tests (Node 16+, no npm install)
node tests/fixtures/build-fixtures.js    # regenerate the fixtures after changing the catalog
node tests/inspect.js some.swf --tags    # inspect any SWF from the command line
```

| Environment | `DecompressionStream` | Result (2026-10-27) |
|---|---|---|
| Node 16.15.0 (Windows) | test-only zlib polyfill (`tests/support/load-reader.js`) | 58 passed, 0 failed |
| Node 22.13.0 (Windows) | native | 58 passed, 0 failed |
| Browsers | native | Not automated. Check manually with the demo; see the README. |

The runtime does not ship the polyfill. In Node, it lets the reader's real streaming code run where the global is missing.

## Fixtures

All fixtures are generated by [`fixtures/build-fixtures.js`](fixtures/build-fixtures.js), using the project's own test writer ([`support/swf-builder.js`](support/swf-builder.js)). They contain no third-party content. `unit/fixtures.test.js` checks two things for each file:

- the committed file still matches the generator. Compressed files are compared by header and inflated content, because zlib output can vary between versions;
- loading the file gives exactly the outcome listed below: the same error code, or the same header values, top-level tag count, diagnostic codes, and unsupported features.

### Valid

| File | Covers | Expected |
|---|---|---|
| `valid/fws-minimal.swf` | FWS, SWF 10, 550×400, 24 fps, FileAttributes, SetBackgroundColor, ShowFrame, End | Loads with no diagnostics and nothing unsupported |
| `valid/cws-minimal.swf` | The same movie compressed as CWS (zlib) | Same structure as the FWS file |
| `valid/fws-timeline.swf` | 2 frames at 12.5 fps; FrameLabel (one in a long header); a 2-frame DefineSprite; PlaceObject with MATRIX + CXFORM; PlaceObject2 with scale/rotate/translate MATRIX, CXFORMWITHALPHA, a UTF-8 name, and a ratio; PlaceObject3 with blend mode and bitmap cache; RemoveObject/RemoveObject2; an empty DefineShape; DoAction | No diagnostics. Unsupported: `tag:DefineShape` (indexed only) and `actionscript:DoAction` (not executed). `reader.test.js` checks every decoded field |
| `valid/fws-unsupported.swf` | Unknown tag code 1000, DoABC, PlaceObject2 clip actions, PlaceObject3 filter list | No diagnostics. Each item is listed in `unsupported`; the placements have status `partial` |
| `valid/fws-nested-sprite.swf` | A sprite inside a sprite plus a DoInitAction inside a sprite (neither is allowed); a sprite that declares 3 frames, has 1, and lacks End | Children are indexed recursively. Warnings: `TAG_NOT_ALLOWED_IN_SPRITE` ×2, `SPRITE_FRAME_COUNT_MISMATCH`, `SPRITE_MISSING_END` |

### Cases without fixture files

These are covered in `unit/*.test.js`:

- **Bit reader:** RECT, MATRIX, CXFORM, and CXFORMWITHALPHA vectors worked out by hand from the specification, independently of the test writer; UB/SB/FB widths 0, 1, 17, and 32; sign extension; fields that span byte boundaries; alignment; reads never cross the reader's end; invalid widths and ranges; and 300 seeded random round trips that start unaligned.
- **Limits:** `maxFileBytes` (for buffers and Blobs), `maxTags` (nested tags included), `maxSpriteDepth` 0 and 1, and option validation.
- **API:** inputs as Uint8Array, ArrayBuffer, Buffer, DataView, and Blob; `getTagData` with valid tags (top-level and nested) and invalid ones; `walkTags`.
- **Version-dependent behavior:** strings are Latin-1 before SWF 6 and UTF-8 from SWF 6; the FrameLabel named-anchor flag is read only from SWF 6; FileAttributes must be present and first from SWF 8; CWS in files older than SWF 6; the AVM2 flag; a stage RECT with min > max; CWS when `DecompressionStream` is missing (`CWS_UNSUPPORTED`).
- **Controlled fuzz:** every byte of `fws-timeline.swf` is mutated 5 ways, and the file is truncated at every length with its declared length adjusted. Each attempt must either load or reject with an `SWFReaderError`; no other exception type is allowed.

## Tag support

| Status | Tags |
|---|---|
| Decoded | `End`, `ShowFrame`, `SetBackgroundColor`, `FrameLabel`, `FileAttributes`, `PlaceObject`, `PlaceObject2`, `PlaceObject3`, `RemoveObject`, `RemoveObject2`, `DefineSprite` (SpriteID, FrameCount, and recursive control tags) |
| Partial | `PlaceObject2`/`PlaceObject3` clip actions; the `PlaceObject3` filter list and the optional fields after it. These are listed in `unsupported` |
| Detected, never executed | `DoAction`, `DoInitAction` (AVM1), `DoABC` (AVM2) |
| Indexed only (offsets + `getTagData`) | Every other named tag: shapes, bitmaps, fonts, text, buttons, sounds, video, morphs, `SymbolClass`, `Metadata`, … |
| Unknown | Any code missing from `SWFReader.tagNames`; skipped using its declared length |
| Rejected | `ZWS` files (LZMA) |

## Manual check on a real file (not a fixture)

This was a third-party SWF of unknown redistribution rights (`visita.swf`, 247 778 bytes). It is not included in the repository. With `node tests/inspect.js` it gives: CWS, SWF 6, 400×250, 24 fps, 20/20 frames, 169 top-level and 639 total tags, 6 sprites, 36 DoAction, and no diagnostics (Node 16 and Node 22).
