SWF Reader v0.6.0 · inspector

Inspect a SWF movie's header, tag structure, decoded fields, diagnostics, and unsupported features. This tool reads files without playing them or executing ActionScript.

Structure inspection only: header, tag index (including DefineSprite contents), and decoded placement records (MATRIX, CXFORM, CXFORMWITHALPHA). ActionScript is detected and listed, never executed. No external libraries. To play a movie, open player.html.

Select a file to get started. Test files: tests/fixtures/; expected results: tests/COMPATIBILITY.md.
