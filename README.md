# RetroFlash.js
A lightweight, dependency-free Flash SWF player and ActionScript runtime, built entirely in JavaScript and HTML5 Canvas. The goal is to bring classic Flash animations and games back to modern browsers without plugins or WebAssembly.

## Current state

RetroFlash.js plays SWF animations on Canvas 2D:

- `DefineShape` 1–4: solid fills, linear, radial and focal gradients, and lines;
- bitmaps:
  - `DefineBits` with `JPEGTables`;
  - `DefineBitsJPEG2/3/4` (JPEG, PNG, or GIF, and JPEG with an alpha plane);
  - `DefineBitsLossless/Lossless2`;
  - bitmap fills, clipped or repeating;
- the display list, built from `PlaceObject`/`RemoveObject`;
- the timelines of the root movie and of nested `DefineSprite` instances;
- `clipDepth` masks;
- **text**:
  - `DefineText` drawn with the glyph outlines of `DefineFont`/`DefineFont2`/`DefineFont3`;
  - `DefineEditText` fields with embedded or device fonts, word wrap, alignment, margins, borders, `AutoSize`, and an HTML subset;
- **buttons** (`DefineButton`/`DefineButton2`): up/over/down states, hit areas, the hand cursor, and pointer and keyboard events with their actions;
- a controlled **AVM1 subset** for timeline control in frame scripts and button actions: `stop`, `play`, `nextFrame`/`prevFrame`, `gotoAndPlay`/`gotoAndStop` by frame or label, and `tellTarget`/`setTarget`. It never evaluates JavaScript or navigates.

AS2 control flow and method calls (`if`, functions, `_root.gotoAndPlay()`) are not followed yet, so text fields bound to variables show only their initial text. Input fields cannot be edited. Sound and morph shapes are not drawn. All of these are listed in `getDiagnostics().unsupported`.

The code lives in [`src/`](./src/) as classic scripts with no dependencies:

| File | Role |
|---|---|
| `src/swf-reader.js` | Parser (`SWFReader`, v0.5): FWS and CWS, a bounds-checked tag index, decoded placements, shapes, bitmap headers, fonts and text, buttons, and filter lists, and `inflate` |
| `src/core/`, `src/display/`, `src/text/`, `src/avm1/`, `src/input/`, `src/render/` | Player modules: dictionary, display list, timelines, bitmap decoding, text layout, buttons and input, the AVM1 subset, and the Canvas renderer |
| `src/retroflash.js` | Player API (`RetroFlash`, v0.4) |
| `src/modules.json` | The load order of every script above |

For use, build the single file `dist/retroflash.min.js`, which holds the reader and the player (see [Build](#build)):

```html
<canvas id="stage"></canvas>
<input id="file" type="file" accept=".swf">
<script src="dist/retroflash.min.js"></script>
<script>
  const player = new RetroFlash.Player({ canvas: document.getElementById('stage') });
  document.getElementById('file').addEventListener('change', async (event) => {
    await player.load(event.target.files[0]);
    player.play();
  });
</script>
```

During development, the source scripts can be loaded directly instead, in the order of `src/modules.json`. The demos do this, so they open directly, with no server and no build:

- [`demo/player.html`](./demo/player.html): the player;
- [`demo/index.html`](./demo/index.html): the structure inspector.

The API is documented in [`src/README.md`](./src/README.md).

## Tests

```sh
node tests/run.js
```

Requires Node 16 or later and installs nothing. `npm run test:dist` builds the bundle and runs the same tests against it. The fixtures are generated by the project itself, in [`tests/fixtures/`](./tests/fixtures/). What is verified, and how, is listed in [`tests/COMPATIBILITY.md`](./tests/COMPATIBILITY.md).

## Build

```sh
npm install      # once: installs terser, the only development dependency
npm run build    # writes dist/retroflash.min.js and dist/retroflash.min.js.map
npm run test:dist
```

The build ([`tools/build.js`](./tools/build.js)) minifies the scripts of `src/modules.json`, in order, into one file with [terser](https://terser.org/), with a source map that points back to `src/`. Before anything is written, the sources and the bundle are each loaded in an isolated context. The bundle has no runtime dependencies. `dist/` is not committed.

The tests and the demos do not need `npm install`.
