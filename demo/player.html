RetroFlash.js Player · v0.4

Plays the vector part of a SWF on Canvas 2D: DefineShape 1–4 (solid fills, linear/radial gradients, lines), the display list, the root and DefineSprite timelines, clipDepth masks, and bitmaps: JPEG, PNG, GIF, JPEG with alpha, and lossless. Static text uses the movie's embedded glyphs. Text fields use embedded or device fonts, with word wrap, alignment and an HTML subset. Frame scripts run through a controlled AVM1 subset, including expressions, control flow, functions, objects, clip events and common MovieClip APIs; unsupported features are reported below. Buttons respond to the mouse (hover, press, release) and to the keyboard once the canvas has focus. Video and text input are not supported yet; sound starts once you click or press a key on the page (browsers require it); what a movie uses is listed below. Links and getURL open in a new tab, and javascript: URLs call the page's functions (never evaluated). The player never fetches anything: when a script loads a movie, an image, variables or a sound (loadMovie, loadVariables, Sound.loadSound), the page answers with the file of the same name added below. Try tests/fixtures/valid/fws-animation.swf, fws-bitmaps.swf, fws-actions.swf, fws-buttons.swf, fws-text.swf or fws-sound.swf. Structure inspector: index.html.
